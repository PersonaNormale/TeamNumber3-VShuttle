# V-Shuttle Frontend (Demo Hackathon)

## Avvio locale

```bash
cd frontend
npm install
npm run dev
```

L'app Vite gira di default su `http://localhost:5173` e usa `/api` come base URL per il backend.

## Note rapide

- Caricare dataset JSON dalla sezione upload.
- Premere **START SIMULATION**.
- Lo stato viene aggiornato con polling HTTP ogni 500ms.
